
# Adventure Game Application

## Introduction

That project aims that is going to show up object-orientated approach and how to implement the main principles such as ncapsulation, abstraction,inheritance, polymorphizm. This game is a surviving game and begins at Safe HOUSE. There are users(Caharacters __Samurai,Archer, Cavailer__) and some obstacles, There has been a battle in between.There are various places where is being used such as River, Forest, Cave. Moreover; Each place has their own specific features. After that battle, one of players beat to other one and bettle ends.
